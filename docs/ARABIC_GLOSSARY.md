# معجم مصطلحات التوثيق العربي

هذا المعجم مرجع تحريري داخلي لاتساق صفحات Nibleaf العربية. لا يُنشر ضمن تنقّل القرّاء، ولا يغيّر أسماء المنتج أو واجهات API أو المعرّفات التقنية.

| English | العربية المعتمدة | ملاحظة الاستخدام |
| --- | --- | --- |
| documentation | التوثيق | استخدم «موقع التوثيق» للموقع المنشور. |
| workspace | مساحة العمل | لا تستبدلها بـ«المشروع» لأنهما كيانان مختلفان. |
| project | المشروع | استخدم «الموقع» فقط عندما يكون اسم عنصر الواجهة Site. |
| page tree | شجرة الصفحات | تشمل الصفحات والمجموعات وترتيب التنقّل. |
| browser editor / visual editor | محرّر المتصفح / المحرّر المرئي | ميّزهما عن وضع المصدر. |
| source mode | وضع المصدر | احتفظ بأسماء Markdown وMDX كما هي. |
| draft / preview | المسودة / المعاينة | حالتان قبل الإصدار المنشور. |
| publish / publishing | النشر / عملية النشر | استخدم الفعل «انشر» في الخطوات. |
| published version | إصدار منشور | لا يعني ضمان الاحتفاظ الأبدي. |
| immutable snapshot | لقطة غير قابلة للتغيير | لقطة إصدار، لا نسخة احتياطية تشغيلية. |
| default branch / branch | الفرع الافتراضي / الفرع | اترك أسماء مثل `main` كما هي. |

| pull request | طلب سحب | و«طلب سحب في حالة مسودة» لـ draft PR. |
| conflict reconciliation | تسوية التعارضات | لا توحِ بحل تلقائي مضمون. |
| import / export | الاستيراد / التصدير | ميّز التصدير عن النسخ الاحتياطي. |
| archive / migration | الأرشفة / الترحيل | اذكر مسار التراجع عند الترحيل. |

| private reader access | وصول خاص للقرّاء | لا تصفه كإدارة هوية مؤسسية عامة. |
| reader / audience | القارئ / الجمهور المستهدف | استخدم كل مصطلح في سياقه. |
| search | البحث | لا تترجم المعرّفات داخل الشيفرة. |
| language switcher | مبدّل اللغة | يعرض نظيرًا موجودًا فعلًا. |
| translation key | مفتاح الترجمة | يربط النظيرين الإنجليزي والعربي. |
| right-to-left | من اليمين إلى اليسار (RTL) | استخدم LTR للشيفرة والنص التقني. |
| metadata / frontmatter | البيانات الوصفية / البيانات الوصفية في مقدمة الملف | لا تترجم قيم المعرّفات. |
| slug | معرّف الرابط (slug) | اترك قيمة المعرّف نفسها. |

| object storage | تخزين الكائنات | اترك أسماء المزوّدين كما هي. |

| production | بيئة الإنتاج | تختلف عن المعاينة والمحلية. |
| troubleshooting | استكشاف الأخطاء وإصلاحها | ابدأ بالملاحظات ثم الاستعادة. |

## قواعد ثابتة

- اكتب العربية الفصحى الحديثة بصيغة مباشرة تتمحور حول مهمة القارئ.
- لا تترجم الأوامر أو المسارات أو أسماء الملفات أو أسماء API أو متغيّرات البيئة أو قيم الحالة.
- استخدم النص العربي المطابق للواجهة عندما تكون التسمية مترجمة داخل المنتج.
- ضع النصوص التقنية المختلطة داخل شيفرة مضمّنة عندما يحسن ذلك اتجاه القراءة.
- لا تضف ضمانات أو سلوكًا أو صورًا غير مثبتة في المستودع أو البيئة المختبرة.
