A theme controls how your published site looks: its layout, spacing, colors, and
the style of code blocks, callouts, and tables. Theme changes are drafts. Readers
keep the current look until you publish.

Open **Settings → Appearance → Themes**, or select **Settings** in the editor and
then **Themes**. You need to be the site's Owner or an Admin. To add your logo
and favicon, use **Branding** in the same list.

## Pick a theme

The **Theme gallery** has three themes, each with a different page layout:

- **Harbor:** a balanced reference layout with the page list on the side, a
  reading column, and an outline of the current page. A good default for product
  guides.
- **Manuscript:** an editorial layout with chapters across the top and a
  comfortable reading width. Suited to long articles and knowledge bases.
- **Signal:** a compact technical layout with dense navigation and wide space for
  code. Suited to developer references.

Sites created before themes were introduced keep their original look until
someone picks or imports a theme.

## Customize it

Adjust the theme in these areas:

- **Default appearance:** light, dark, or system. Readers can still switch.
- **Layout and navigation:** **Structural shell**, **Density**,
  **Content width**, **Header**, **Sidebar**, **Navigation**, and corner shapes.
- **Content components:** how **Code blocks**, **Callouts**, **Cards**, **Tabs**,
  and **Tables** look.
- **Semantic colors:** colors for text, backgrounds, links, and highlights in
  light and dark mode.

The **Live preview** shows your changes straight away. Switch it between English
and Arabic and between light and dark before you save.

Nibleaf checks that text stays readable against its background. If it shows
**Contrast needs attention**, fix the listed color pairs before you can save.

- **Undo** reverses your last change.
- **Reset preset** returns to the theme's original settings.
- **Save changes** saves the draft theme. Then
  [publish](/product/publishing) so readers see it.

## Share a theme with a template file

A theme template is a small JSON file that holds only theme settings. It never
contains your pages, team, analytics, passwords, or code.

- To save one, open **Theme templates** and select **Export theme**.
- To use one, paste its contents or select **Choose JSON file**. Choose **Merge**
  to change only the settings in the file, or **Replace theme** to reset the
  theme first and then apply the file. Select **Preview import** to see every
  proposed change, then **Apply to draft**.

Importing never publishes on its own, and it never changes your pages, SEO,
navigation, or other settings. Template files can be up to 128 KiB. Files that
contain scripts or styling code are rejected.

## Undo a theme change

Before a big change, export your current theme. To go back, import that file with
**Replace theme**, check the preview, apply it to the draft, and publish.

Older published versions and exports are never changed by a theme edit. A theme
template is not a backup of your site; for that, see
[Export and archive](/product/exports).
