An export is a copy of your site you can download and keep. Nibleaf exports your
latest **published** version, not your current drafts, so every format you pick
in one run contains the same content.

Open **Settings → Exports**. Owners, Admins, and Editors can create one-time
exports. Only Owners and Admins can manage schedules.

## Create a one-time export

1. Publish your site first. Without a published version, Nibleaf shows
   "Publish the site first, then you can export it."
2. Open **One-time export** and select one or more formats:
   - **Markdown ZIP:** your pages as Markdown files. Use it to move your docs or
     keep an editable copy.
   - **PDF:** a printable document, including right-to-left text. Use it for
     reviews, approvals, or printing.
   - **Static HTML ZIP:** a complete offline website with navigation, search, and
     your theme. Use it to host the docs somewhere else.
3. Select **Create export**.

The run appears in **Run history** with its status: pending, running, and then
succeeded or failed. Download links appear when a run succeeds. They stop
working after a short time, so download the file promptly. A failed export never
changes your published site; check the error, fix the cause, and create a new
export.

To download every draft page instead, including unpublished ones, select
**Download the original Markdown ZIP** under **One-time export**.

## Schedule regular archives

1. Open **Schedules** and select **New schedule**.
2. Enter a **Schedule name**, choose the formats, and choose **Daily**,
   **Weekly**, or **Monthly**.
3. Set the **IANA timezone**, such as `Africa/Tunis` or `Asia/Riyadh`, and the
   **Local run time**. Using a named time zone keeps the run at the same local
   time when clocks change.
4. Set **Runs to retain** and **Retention days**. Older copies are deleted after
   either limit.
5. Select **Create schedule**.

Select **Run now** to test a schedule straight away, then check the result in
**Run history**. Use **Disable** to pause a schedule.

## Test that your copy works

An export you've never opened is not a recovery plan. Download a fresh copy of
each format you rely on and check it outside Nibleaf:

- **Markdown:** open a few files and check titles, links, and images.
- **Static HTML:** unzip it, open it in a browser while offline, and follow a few
  links.
- **PDF:** check long pages, Arabic pages, diagrams, and code.

Write down which published version you exported, where you stored the file, and
who is responsible for restoring it.

## What an export doesn't include

Exports don't include your team, drafts that aren't published, comments,
analytics, passwords, or keys. They are an extra copy, not a full backup. If you
host Nibleaf yourself, also follow the
[backup and restore guide](/self-hosting/backups-upgrades). Operators can find
the export limits and worker settings in the
[environment variable reference](/reference/environment-variables).
