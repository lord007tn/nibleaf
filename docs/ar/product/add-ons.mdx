الإضافات ميزات اختيارية يمكنك تفعيلها لموقعك، مثل زر «هل كانت هذه الصفحة مفيدة؟»
أو فحوص تعمل قبل النشر. افتح **الإعدادات ← الإضافات**. يجب أن تكون مالك الموقع أو
مشرفًا.

تعرض كل إضافة حالتها: **نشطة** أو **غير نشطة** أو **تحتاج إلى إعداد** أو **غير
متاحة**. وتعني «غير متاحة» أن خطتك لا تشملها. أما الإضافات الموسومة بـ**تجريبية**
فما زالت قيد الاختبار. استخدم مفتاح التبديل في كل إضافة لتشغيلها أو
إيقافها. تُطبَّق التغييرات على موقعك المنشور فورًا دون الحاجة إلى نشر جديد.

الاتصالات بالخدمات الخارجية، مثل Google Analytics أو Slack، ليست إضافات، وتجدها
في **الإعدادات ← التكاملات**.

## تفاعل القرّاء

| الإضافة | ما يراه القرّاء |
| --- | --- |
| **أداة الملاحظات** | سؤال «هل كانت هذه الصفحة مفيدة؟» مع **نعم** و**لا**. تظهر النتائج في **التحليلات ← آراء القرّاء**. |
| **اقتراحات التحرير** | رابط يفتح مصدر الصفحة في أداة مثل GitHub ليقترح القرّاء تعديلًا. |
| **فتح المشاكل** | رابط يفتح نموذج مشكلة جديدة، على GitHub مثلًا، مع تعبئة الصفحة مسبقًا. |

لا تسجّل أداة الملاحظات إلا «نعم» أو «لا» للصفحة، ولا يستطيع القرّاء كتابة تعليق.
اختر **الموضع** (**بعد محتوى الصفحة** أو **بعد روابط السابق والتالي**) و**طريقة
العرض** (**صف مدمج** أو **بطاقة**).

تحتاج روابط التحرير والمشاكل إلى قالب عنوان ويب قبل أن تعمل. استخدم `{path}` في
موضع مسار الصفحة، ويمكن لروابط المشاكل أيضًا استخدام `{url}` لعنوان الصفحة الكامل.
مثال:

- قالب رابط التحرير: `https://github.com/acme/docs/edit/main/{path}.mdx`
- قالب رابط المشكلة: `https://github.com/acme/docs/issues/new?body={url}`

يجب أن يبدأ القالب بـ `https://` أو `http://`، ولا يجوز أن يتضمن كلمة مرور. افتح
صفحة داخل مجموعة في **معاينة**، واختر الرابط لتتأكّد من أنه يفتح المكان الصحيح.

## الخصوصية والموافقة

يطلب **شريط الموافقة** إذن القرّاء قبل تحميل التحليلات الاختيارية. يستطيع القرّاء
القبول أو الرفض، وتغيير اختيارهم لاحقًا، ويُحفظ اختيارهم في متصفحهم.

يمكنك اختيار **موضع البطاقة** و**كثافة البطاقة** و**تخطيط الإجراءات**. تغيّر هذه
الخيارات شكل الشريط فقط، ولا تغيّر ما يسمح به.

إذا أوقفت شريط الموافقة، تبقى التحليلات الاختيارية محجوبة، فهي لا تُحمَّل أبدًا دون
سؤال. تحقّق من الشريط في نافذة بحجم الهاتف، وبكل لغات موقعك.

## فحوص النشر

| الإضافة | ما تفعله |
| --- | --- |
| **فحوصات CI** | تشغّل الفحوص أدناه. وإذا كانت متوقفة، لا يعمل أي منها. |
| **فحص الروابط المعطلة** | يوقف النشر عندما يشير رابط إلى صفحة غير موجودة في اللغة والإصدار نفسيهما. |
| **مدقق القواعد** | ينبّه إلى مشاكل القواعد والصياغة أثناء النشر. هذه الإضافة تجريبية. |
| **معاينات النشر** | تتيح لفريقك معاينة التغييرات غير المنشورة قبل الإصدار. |

عندما يوقف فحصٌ النشرَ، تعرض نظرة عامة على الموقع عملية النشر الفاشلة وقائمة
المشاكل. أصلح الروابط المعطّلة ثم انشر مجددًا. وإذا بقيت ملاحظات لغوية فقط،
فيمكنك اختيار **انشر على أي حال**. أبقِ **فحوصات CI** مفعّلة ما لم تحتج إلى استثناء
مؤقت، ثم صحّح الصياغة لاحقًا.

## للمطوّرين والاستضافة الذاتية

يمكن أيضًا قراءة الإضافات وتغييرها عبر واجهة API باستخدام مفتاح API يملك صلاحية
`addons:read` أو `addons:write`. وتستطيع مساعدات الذكاء الاصطناعي المتصلة عبر MCP
قراءة الإضافات لكنها لا تستطيع تغييرها. راجع [مرجع API](/ar/reference/api)
و[ربط عملاء MCP بأمان](/ar/self-hosting/mcp). وعلى من يستضيف ذاتيًا ويرقّي من
إصدار أقدم اتباع [دليل ترحيل الإصدار المجمّع](/ar/self-hosting/combined-release-migration).
