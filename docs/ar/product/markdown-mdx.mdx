تُحفظ كل صفحة في Nibleaf بصيغة Markdown، وهي صيغة نصية تضيف فيها الرموز التنسيق،
مثل `**bold**` للخط العريض. وتضيف MDX مكوّنات تُكتب مثل وسوم HTML لتخطيطات أغنى،
كالتبويبات والبطاقات. يكتب المحرّر المرئي ذلك نيابةً عنك، فاستخدم هذا المرجع عندما
تختار **التحرير بصيغة Markdown (متقدم)** في المحرّر.

تحقّق دائمًا من تغييراتك في **معاينة**، فقد يظهر نص Markdown صحيح بشكل مختلف عمّا
توقعته.

## التنسيق الأساسي

يدعم Nibleaf صيغة Markdown القياسية وامتدادات GitHub: العناوين، والخط العريض
والمائل، والروابط، والصور، والاقتباسات، والقوائم، وقوائم المهام، والجداول، والنص
المشطوب، والشيفرة المضمّنة، وكتل الشيفرة.

- اضبط عنوان الصفحة في حقل العنوان في المحرّر، لا بعنوان `#`. ابدأ الأقسام بـ `##`
  ولا تتخطَّ المستويات.
- أضف لغة لكل كتلة شيفرة لتُلوَّن بشكل صحيح، ويمكنك أيضًا إضافة عنوان:

````md
```bash title="Start Nibleaf"
docker compose -f docker-compose.prod.yml up -d
```
````

## التنبيهات

تبرز التنبيهات ملاحظة أو نصيحة أو تحذيرًا. ويعمل أسلوب GitHub في المحرّر المرئي
وفي Markdown معًا:

```md
> [!WARNING]
> Back up Postgres and object storage before an upgrade.
```

الأنواع المدعومة هي `NOTE` و`TIP` و`CHECK` و`WARNING` و`CAUTION` (يُعرض خطرًا)
و`IMPORTANT` (يُعرض معلومة). ويمكنك أيضًا كتابة `<Note>` أو `<Tip>` أو `<Check>`
أو `<Warning>` أو `<Danger>` أو `<Callout type="warning">`.

## المكوّنات الكتلية

| المكوّن | الاستخدام | الخصائص |
| --- | --- | --- |
| `Card`، `CardGroup` | روابط إلى صفحات ذات صلة تُعرض بطاقات | للبطاقة `title` و`href` و`icon`، وللمجموعة `cols` |
| `Steps`، `Step` | خطوات مرقّمة | للخطوة `title` |
| `Tabs`، `Tab` | بدائل، مثل تبويب لكل نظام تشغيل | للتبويب `title` |
| `Accordion`، `AccordionGroup` | تفاصيل اختيارية يوسّعها القارئ | `title`، `defaultOpen` |
| `Expandable` | تفاصيل متداخلة، غالبًا داخل حقول API | `title`، `defaultOpen` |
| `Columns`، `Column` | محتوى متجاور | لا توجد |
| `Frame` | صورة أو فيديو مع تعليق | `caption` |
| `Banner` | رسالة بارزة | `type` |
| `Update` | مدخل في سجل التغييرات | `label`، `description` |
| `CodeGroup` | عدة كتل شيفرة تُعرض تبويبات | تصبح لغة كل كتلة اسم تبويبها |
| `ParamField`، `ResponseField` | معاملات API وحقول الاستجابة | `name` و`type` و`required` و`default` و`deprecated`، ويقبل `ParamField` أيضًا `path` و`query` و`header` و`body` |
| `ApiExample`، `RequestExample`، `ResponseExample` | طلب واستجابته | `title`، وللاستجابة `status` |
| `FileTree`، `Folder`، `File` | رسم لبنية مجلدات | `name`، وللمجلد `defaultOpen`، وللملف `icon` |
| `RelatedContent`، `RelatedCard` | روابط «اقرأ أيضًا» في نهاية الصفحة | `title`، وللبطاقة `description` و`href` و`icon` |

ضع كل وسم مكوّن في سطر مستقل، واترك سطرًا فارغًا حول نص Markdown داخله:

```mdx
<Steps>
  <Step title="Create a backup">

  Run the backup script and record the output files.

  </Step>
</Steps>
```

لا تعرض شجرة الملفات إلا الأسماء التي تكتبها، ولا تقرأ ملفات حقيقية. وكذلك لا تعرض
أمثلة API وبطاقات الروابط ذات الصلة إلا ما تكتبه.

تعمل التبويبات ومجموعات الشيفرة والأقسام القابلة للطي وأشجار الملفات بلوحة
المفاتيح. وفي التبويبات تنقلك مفاتيح الأسهم بين العناوين وفق اتجاه القراءة في
العربية.

## المكوّنات المضمّنة

| المكوّن | الاستخدام | الخصائص |
| --- | --- | --- |
| `Tooltip` | تعريف قصير يظهر عند التمرير أو التركيز | `tip` |
| `Icon` | أيقونة صغيرة من المجموعة المضمّنة | `icon` أو `name`، و`color` و`size` |
| `Badge` | تسمية صغيرة مثل «تجريبي» | `color` |
| `Button` | رابط بشكل زر | `href`، و`variant` (القيمة `outline` لزر بإطار) |

مثال: `<Tooltip tip="A plain-language definition">term</Tooltip>`.

لا تضع تعليمات ضرورية داخل تلميح، ولا تعتمد على الأيقونة وحدها لنقل المعنى.

## المعادلات الرياضية والمخططات

- **المعادلات:** اكتب المعادلة المضمّنة بين علامتي دولار مفردتين، والمعادلة الكتلية
  بين علامتي دولار مزدوجتين.
- **المخططات:** اكتب مخطط Mermaid داخل كتلة شيفرة موسومة بـ `mermaid`.

اشرح دائمًا الفكرة الرئيسية للمخطط في النص أيضًا، فبعض القرّاء لا يستطيعون رؤية
المخططات، والبحث لا يستطيع قراءتها.

## الشيفرة غير المدعومة أو المخصّصة

يحذف Nibleaf النصوص البرمجية ومعالجات الأحداث والخصائص غير المعروفة عند عرض
الصفحة. وإذا استخدمت الصفحة مكوّنًا غير وارد في هذا المرجع، يحتفظ به المحرّر المرئي
كما كُتب تمامًا ويتيح لك تعديل المحتوى المحيط به. لا يستطيع Nibleaf ضمان عرض
المكوّنات المخصّصة، لذا تحقّق من الصفحة المنشورة وفضّل المكوّنات الواردة هنا.
