يتضمن Nibleaf ثلاث سمات أصلية. **Harbor** سمة هادئة ومتوازنة تصلح افتراضيًا
للمكتبات التي تجمع الأدلة والمراجع. وتمنح **Manuscript** القراءة الطويلة خلفية
أدفأ وعرضًا أكثر تركيزًا. أما **Signal** فتستخدم إيقاعًا تقنيًا كثيفًا لمكتبات
واجهات API والهندسة الكبيرة. الأسماء والرموز والتخطيطات والأصول تنفيذ يملكه
Nibleaf. ألهمت منتجات التوثيق العامة أنماط المنتج العامة، مثل معرض الإعدادات
المسبقة والتخصيص الدلالي والمعاينة قبل النشر، لكن Nibleaf لا ينسخ شيفرتها أو
أصولها أو أسماءها أو مظهرها التجاري المملوك.

تحتفظ المشاريع المنشأة قبل مخطط السمة v1 بألوانها وتخطيطها الحاليين إلى أن
يختار المالك سمة أو يخصصها أو يستوردها. يمنع وضع التوافق هذا تغييرًا مرئيًا غير
مطلوب في موقع منشور قائم.

## حدود الإلهام والملكية

راجعت عملية التصميم إرشادات التخصيص والتنقل العامة في
[Fumadocs](https://www.fumadocs.dev/docs/guides/customize-ui) و
[Mintlify](https://www.mintlify.com/docs/organize/settings-appearance) و
[ReadMe](https://docs.readme.com/main/docs/design-themes). أثّرت هذه المصادر في
توقعات عامة، مثل الإعدادات المسبقة والإعدادات الدلالية وخيارات التخطيط ومسار
العمل الذي يبدأ بالمعاينة. تستخدم Harbor وManuscript وSignal أسماء وقيم رموز
ومعالجات مكونات وشيفرة وأصولًا أصلية يملكها Nibleaf. أسماء المنتجات في هذه
الفقرة ملك لأصحابها ولا تعني وجود ارتباط بهم.

## تخصيص المسودة بأمان

افتح **محرر الموقع ← السمات**. اختر سمة بداية، ثم عدّل المظهر والكثافة وعرض
المحتوى ونصف القطر والرأس والشريط الجانبي والتنقل والشيفرة والتنبيهات والبطاقات
والتبويبات والجداول والألوان الدلالية للوضعين الفاتح والداكن. تستطيع المعاينة
التبديل مستقلًا بين العربية والإنجليزية وبين الوضعين الفاتح والداكن.

يتحقق المحرر من تباين النص واللون البارز قبل الحفظ. يعيد **التراجع** التعديل
السابق، ويستعيد **إلغاء التغييرات** آخر إعدادات مشروع محفوظة، ويعيد **إعادة
الضبط** الإعداد المسبق المختار. تؤثر هذه الإجراءات في المسودة وحدها. تظل عملية
النشر الحالية ذات الحالة `READY` ظاهرة للعامة حتى نشر المشروع من جديد. عاين
اتجاهي اللغة ووضعَي الألوان قبل النشر.

تستهلك مكونات السمة متغيرات دلالية ثابتة، مثل `--theme-canvas` و
`--theme-foreground` و`--theme-surface` و`--theme-accent` و`--theme-focus`
و`--theme-code`. يستخدم البحث الواجهة نفسها، ويمكن لأسطح الذكاء الاصطناعي
المستقبلية اعتمادها عبر `data-theme-surface="ai"` من دون الارتباط بالبنية
الداخلية لمصيّر الصفحة.

## تصدير قالب وفحصه

اختر **تصدير** لتنزيل ملف JSON قانوني بترميز UTF-8. تُرتب المخرجات ترتيبًا
حتميًا كي تظل المراجعات ومقارنات دورة التصدير والاستيراد مفيدة. لا يحتوي الملف
إلا الإعدادات التي تملكها السمة: بياناتها الوصفية ورموزها، إلى جانب مراجع
العلامة والخطوط المدعومة. ولا يتضمن المحتوى أو بيانات الاعتماد أو الأعضاء أو
التحليلات أو شيفرة قابلة للتنفيذ.

```json
{
  "kind": "nibleaf-theme",
  "version": 1,
  "metadata": {
    "name": "Product docs theme",
    "description": "Shared theme for product documentation",
    "author": "Documentation team"
  },
  "config": {
    "theme": {
      "preset": "harbor"
    },
    "styling": {
      "theme": "system"
    }
  }
}
```

لا يقبل مخطط v1 إلا حقولًا معروفة ومحدودة. الحد الأقصى للقالب 128 KiB، و12
مستوى من التداخل، و600 قيمة يجري المرور عليها. يجب أن تكون مراجع الأصول روابط
HTTPS أو مسارات تبدأ من الجذر من دون انتقال بين الأدلة أو بيانات اعتماد أو
مضيفات نسبية للبروتوكول. تفشل الحقول المجهولة وCSS أو JavaScript القابلان
للتنفيذ ومفاتيح تلويث النماذج الأولية وإصدارات المخطط المستقبلية برسائل قابلة
للتنفيذ. يرحّل المستورد صيغة v0 القديمة الموثقة إلى v1 قبل التحقق.

## معاينة الاستيراد وتطبيقه

ألصق JSON أو اختر ملفًا، وحدد **دمج** أو **استبدال**، ثم عاين التغييرات الدقيقة.
يحدّث الدمج الحقول الواردة في القالب ويحتفظ بإعدادات السمة الأخرى. ويعيد
الاستبدال ضبط الإعدادات التي تملكها السمة أولًا. لا يغيّر أي وضع تحسين محركات
البحث أو التنقل أو المحتوى أو التحليلات أو الوصول أو إعدادات المشروع الأخرى.

طلب الاستيراد الأول معاينة جافة. لا تطبق التغييرات إلا بعد مراجعة القائمة
وتحذيرات إمكانية الوصول. يحدّث التطبيق مسودة المشروع، ولا ينشرها سرًا. انشر
صراحة، وتحقق من عملية النشر الناتجة، واحتفظ بالقالب السابق المصدّر كنقطة رجوع.

## التراجع عن سمة

صدّر القالب الحالي قبل تغيير مهم للسمة. للتراجع، استورد ذلك الملف باستخدام
**استبدال**، وراجع الفرق، وطبقه على المسودة، ثم انشر عملية نشر جديدة. تظل عمليات
النشر السابقة غير القابلة للتغيير ونواتج التصدير المنشأة سابقًا من دون تغيير.
وإذا فشل التحقق من الاستيراد، فلا تُكتب أي إعدادات للمشروع.

للحصول على أرشيف كامل للمحتوى والموقع، استخدم [التصديرات المنشورة](/ar/product/exports).
قوالب السمات ملفات صغيرة لتبادل التصميم، وليست نسخًا احتياطية للمشروع.
