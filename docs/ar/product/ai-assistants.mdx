يستطيع مساعد الذكاء الاصطناعي المتصل بـ Nibleaf أن يجيب عن سؤال مثل «ما الذي
يبحث عنه القرّاء ولا يجدونه؟»، وأن يقرأ الصفحات المعنية، ويصوغ إصلاحًا، ويجهّزه
للنشر، وكل ذلك داخل موقع واحد. يعتمد المساعد على بروتوكول Model Context
Protocol (MCP)، وهو معيار مفتوح يتيح لتطبيقات الذكاء الاصطناعي استخدام أدوات
خدمات أخرى. وتربطه إما بتسجيل الدخول إلى Nibleaf من داخل المساعد، وإما بمفتاح
شخصي تنشئه بنفسك. لا يستطيع المساعد أبدًا أن يتجاوز ما
تستطيع أنت فعله في لوحة التحكم، ولا يصل شيء مما يكتبه إلى القرّاء قبل تأكيد النشر
بناءً على معاينة حديثة. يتحقق Nibleaf من المعاينة، لا من الشخص: فخطوة المراجعة
تعتمد على مساعد يسألك أولًا، لذلك امنح الأتمتة التي تعمل دون إشراف مفتاح **القراءة
فقط**.

## قبل أن تبدأ

- يجب أن يكون MCP مفعّلًا في نسخة Nibleaf التي تستخدمها. في الاستضافة الذاتية
  يفعّله المشغّل؛ راجع [ربط عملاء MCP بأمان](/ar/self-hosting/mcp). وإذا كان
  معطّلًا فستذكر صفحة الإعدادات أن الاتصال بمساعدي الذكاء الاصطناعي معطّل في هذه
  النسخة، وسيتلقى كل عميل الرمز `mcp:disabled`.
- يجب أن تكون ضمن فريق الموقع، بأي دور. يستطيع كل أعضاء الفريق ربط مساعد أو
  إنشاء مفتاح لأنفسهم من **الإعدادات ← مساعدو الذكاء الاصطناعي (MCP)**. راجع
  [ادعُ فريقك](/ar/product/team) لمعرفة الأدوار.
- ثبّت المساعد الذي ستستخدمه: ChatGPT أو Claude ‏(claude.ai أو Claude Desktop) أو
  Claude Code أو Cursor أو VS Code مع إضافة محادثة تدعم MCP.

## اختر ما يُسمح للمساعد بفعله

يبدأ كل اتصال وكل مفتاح من إعداد مسبق يظهر تحت **صلاحيات المساعد** (أو تحت **ما
يمكن للتطبيق فعله** عند الربط بتسجيل الدخول). اختر أصغر إعداد يغطي المهمة.

| الإعداد المسبق | من يمكنه اختياره | يستطيع المساعد | لا يستطيع المساعد |
| --- | --- | --- | --- |
| **القراءة فقط** | الجميع | قراءة بيانات المشروع والصفحات ومحتواها واللغات والإصدارات والتحليلات المجمّعة، ومحادثات «اسأل المساعد» المحفوظة (الأسئلة بعد حذف البيانات الحساسة منها والإجابات وآراء القرّاء)، وإعدادات البحث وسلامته وعمليات النشر. | رؤية عبارات البحث الفردية، أو تغيير أي صفحة، أو النشر. |
| **مساعد كتابة الدعم** | الجميع | كل ما في «القراءة فقط»، إضافة إلى قراءة عبارات البحث الأكثر تكرارًا والفاشلة، وإنشاء مسودات الصفحات وتعديلها، ونقل الصفحات وترجمتها وإخفائها وإظهارها، والنشر بعد تأكيد معاينة حديثة. | حذف الصفحات، أو تغيير الإعدادات أو الأعضاء أو الفوترة أو السمات أو الإضافات أو التكاملات، أو النشر من دون معاينة حديثة مؤكَّدة. |
| **إدارة كاملة** | المشرفون والمالك | كل عمليات القراءة والكتابة التي يوفرها خادم MCP، ومنها قراءة الاستخدام والاستحقاقات والإضافات والسمات والتصدير وحالة التكاملات. | أي شيء لا يوفره الخادم أصلًا: حذف المحتوى، أو بيانات الاعتماد، أو المدفوعات، أو تشغيل الشيفرة. |

يرى المحرّرون خيار **إدارة كاملة** مع الملاحظة «متاح للمسؤولين فقط.»، ولا يمكنهم
اختياره.

تنطبق قاعدتان فوق كل إعداد مسبق:

- **الاتصال أو المفتاح يعمل باسمك.** يعيد Nibleaf في كل طلب التحقق من دورك
  الحالي وحالة حسابك. فإذا أزالك مشرف من مساحة العمل أو علّق حسابك أو حُذف
  حسابك، تتوقف تطبيقاتك المتصلة ومفاتيحك عند طلبها التالي.
- **عبارات البحث بيانات اختيارية.** لا تتوفر عبارات البحث الفردية إلا بالشروط
  الواردة في قسم «ما الذي تخبرك به التحليلات وما لا تخبرك به» أدناه. وفي غير ذلك
  تعيد أدوات عبارات البحث الأعداد من دون العبارات وتذكر السبب.

## اربط عبر تسجيل الدخول

تسجيل الدخول هو أسرع طريقة للربط، والطريقة الوحيدة لـ ChatGPT ولموصلات claude.ai
وClaude Desktop. تضيف عنوانًا واحدًا إلى المساعد؛ ولا يوجد مفتاح لنسخه أو حفظه.
تعرض **الإعدادات ← مساعدو الذكاء الاصطناعي (MCP)** العنوان تحت **الربط عبر تسجيل
الدخول (موصى به)**: عنوان لوحة التحكم متبوعًا بـ `/api/mcp`. تستخدم الأمثلة التالية
العنوان `https://docs.example.com/api/mcp`. وإذا ذكر ذلك الصندوق أن تسجيل الدخول
يتطلب HTTPS، فالنسخة لا تُخدَم عبر HTTPS؛ فاستخدم
[مفتاحًا شخصيًا](/ar/product/ai-assistants) بدلًا من ذلك.

1. أضف العنوان إلى مساعدك كما هو موضّح لكل عميل أدناه.
2. يفتح المساعد Nibleaf في متصفحك. سجّل الدخول كالمعتاد، برمز البريد الإلكتروني أو
   بحساب Google.
3. اختر المشروع الذي يخصّه هذا الاتصال وما يُسمح للمساعد بفعله فيه: **القراءة
   فقط**، أو **مساعد كتابة الدعم**، أو **إدارة كاملة** (للمشرفين والمالك فقط).
   والإعدادات المسبقة هي نفسها الموضّحة في قسم «اختر ما يُسمح للمساعد بفعله».
4. راجع الملخّص: التطبيق، والمشروع، وما سيستطيع فعله وما لن يستطيعه بكلمات بسيطة.
   اختر **سماح**. ستعود إلى المساعد، وقد أصبح متصلًا بذلك المشروع وحده.

يعرض التطبيق الذي سجّل نفسه بنفسه تحذيرًا بأن اسمه غير موثَّق، وتعرض الصفحة المكان
الذي ستعود إليه. لا تتابع إلا إذا بدأت الربط من ذلك التطبيق. وللعمل على مشروع آخر،
اربط المساعد مرة أخرى واختر ذلك المشروع.

### سجّل الدخول من ChatGPT

في ChatGPT، افتح **Settings ← Apps & Connectors**، وفعّل وضع المطوّر، وأضف موصلًا
مخصّصًا. الصق العنوان، واختر OAuth طريقةً للمصادقة، ثم سجّل الدخول عندما يفتح
ChatGPT موقع Nibleaf.

### سجّل الدخول من Claude

في claude.ai أو Claude Desktop، افتح **Settings ← Connectors ← Add custom
connector**، والصق العنوان، ثم اختر **Connect** وسجّل الدخول. والموصل متاح في
كليهما.

### سجّل الدخول من Claude Code

أضف الخادم بعنوانه فقط:

```bash
claude mcp add --transport http nibleaf "https://docs.example.com/api/mcp"
```

شغّل Claude Code، ثم نفّذ `/mcp`، واختر `nibleaf`، ثم **Authenticate**. يحفظ Claude
Code الرموز في مخزن بيانات الاعتماد الخاص به ويجدّدها.

### سجّل الدخول من Cursor أو VS Code

أضف الخادم بعنوانه فقط؛ يفتح المحرّر صفحة تسجيل الدخول أول مرة يتصل فيها. في
Cursor، احفظ ما يلي باسم `.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "nibleaf": {
      "url": "https://docs.example.com/api/mcp"
    }
  }
}
```

وفي VS Code، احفظ ما يلي باسم `.vscode/mcp.json`:

```json
{
  "servers": {
    "nibleaf": {
      "type": "http",
      "url": "https://docs.example.com/api/mcp"
    }
  }
}
```

### إدارة التطبيقات المتصلة

تظهر التطبيقات التي ربطتها عبر تسجيل الدخول تحت **الإعدادات ← مساعدو الذكاء
الاصطناعي (MCP) ← التطبيقات المتصلة**، مع إعدادها المسبق ووقت آخر استخدام وآخر
نشاط؛ ويرى المشرفون أيضًا من ربط كل تطبيق. اختر **فصل** لإيقاف تطبيق فورًا. يرى
المحرّرون تطبيقاتهم ويفصلونها، ويرى المشرفون والمالك تطبيقات الجميع ويفصلونها.
ويتوقف الاتصال أيضًا عندما يغادر الشخص الذي أنشأه مساحة العمل أو يُوقَف. ويجب ربط
التطبيق المفصول وتسجيل الدخول من جديد. وربط التطبيق نفسه بالمشروع نفسه مرة أخرى يحلّ
محل اتصالك السابق.

## أنشئ مفتاحك الشخصي

1. افتح المشروع، ثم **الإعدادات ← مساعدو الذكاء الاصطناعي (MCP)**.
2. أعطِ المفتاح اسمًا يدل على مكان استخدامه (مثل «الحاسوب المحمول –
   Claude Code»)، واختر إعدادًا مسبقًا، ومدة صلاحية من 7 أو 30 أو 90 أو 180 أو
   365 يومًا (90 يومًا افتراضيًا)، ثم اختر **إنشاء مفتاح**. ولاختيار النطاقات
   واحدًا واحدًا بدل الإعداد المسبق، افتح **خيارات متقدمة: اختر الصلاحيات**.
3. انسخ السر؛ فهو لا يظهر إلا مرة واحدة. ألصقه مباشرة في المساعد أو في مدير
   كلمات المرور، ولا تضعه أبدًا في محادثة أو تذكرة أو لقطة شاشة أو ملف تحفظه في
   مستودع. وبعد حفظه، اختر **حفظت المفتاح — إخفاء**.

اختر **اختبار الاتصال** لتتأكد من أن المفتاح وعنوان الخادم وتفعيل MCP في النسخة
تعمل جميعًا قبل ضبط أي عميل. وعند النجاح تظهر الرسالة «تم الاتصال · N أداة
متاحة»، حيث N عدد الأدوات التي يستطيع مفتاحك استخدامها.

تعرض قائمة المفاتيح الإعداد المسبق لكل مفتاح، وآخر استخدام له، وآخر نشاط له،
ويرى المشرفون كذلك مالك كل مفتاح. يرى المحرّرون مفاتيحهم فقط ويلغونها. أما
المشرفون والمالك فيرون مفاتيح الجميع ويستطيعون إلغاء أي منها، لكن مالك المفتاح
وحده يستطيع تدويره. يلغي التدوير السر القديم ويصدر سرًا جديدًا يعمل باسم الشخص
الذي دوّره.

## اربط المساعد

تعرض لوحة الإعداد المجاورة لمفتاحك الجديد أمرًا أو رابطًا أو إعدادًا جاهزًا لكل
عميل، وعنوان الخادم مملوء مسبقًا. تستخدم الأمثلة التالية العنوان
`https://api.docs.example.com/api/mcp` والعنصر النائب `YOUR_NIBLEAF_KEY`؛ فاستبدل
بهما القيم الظاهرة في لوحة الإعداد لديك.

### Claude Code

1. انسخ الأمر من لوحة الإعداد؛ فهو يتضمن مفتاحك.
2. شغّله في الطرفية:

```bash
claude mcp add --transport http nibleaf "https://api.docs.example.com/api/mcp" --header "Authorization: Bearer YOUR_NIBLEAF_KEY"
```

3. شغّل Claude Code ونفّذ `/mcp`؛ يجب أن يظهر `nibleaf` متصلًا.

لأن المفتاح جزء من الأمر، تحفظه الطرفية في سجل الأوامر، فاحذف ذلك الإدخال من
السجل بعد التنفيذ، خاصة على جهاز مشترك. أبقِ النطاق المحلي الافتراضي، ولا تضف
`--scope project`، لأن ذلك يكتب المفتاح في ملف `.mcp.json` الذي يُحفظ عادة في
المستودع.

### Claude Desktop

يصل Claude Desktop إلى خادم بعيد يتطلب مفتاحًا عبر الجسر `mcp-remote`، وهو يحتاج
إلى Node.js.

1. افتح ملف إعداد Claude Desktop:
   `~/Library/Application Support/Claude/claude_desktop_config.json` في macOS، أو
   `%APPDATA%/Claude/claude_desktop_config.json` في Windows.
2. ألصق الكتلة الظاهرة في لوحة الإعداد؛ فهي تتضمن مفتاحك:

```json
{
  "mcpServers": {
    "nibleaf": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://api.docs.example.com/api/mcp",
        "--header",
        "Authorization:${NIBLEAF_AUTH}"
      ],
      "env": {
        "NIBLEAF_AUTH": "Bearer YOUR_NIBLEAF_KEY"
      }
    }
  }
}
```

3. أغلق Claude Desktop تمامًا وأعد فتحه، ثم تحقق من ظهور أدوات Nibleaf في قائمة
   الأدوات.

تُمرَّر قيمة الترويسة عبر `env` ومن دون مسافة بعد النقطتين، حتى يستلمها الجسر
سليمة على كل أنظمة التشغيل.

### Cursor

1. اضبط متغيّر البيئة `NIBLEAF_API_KEY` على مفتاحك في البيئة التي يعمل منها
   Cursor.
2. اختر **إضافة إلى Cursor** في لوحة الإعداد وأكّد التثبيت في Cursor. لا يتضمن
   الرابط أي سر، إذ يقرأ الإدخال المثبّت المفتاح من `NIBLEAF_API_KEY`. ولضبط
   Cursor يدويًا بدلًا من ذلك، احفظ ما يلي في `.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "nibleaf": {
      "url": "https://api.docs.example.com/api/mcp",
      "headers": {
        "Authorization": "Bearer ${env:NIBLEAF_API_KEY}"
      }
    }
  }
}
```

3. أعد تشغيل Cursor وتحقق من أن الخادم `nibleaf` يظهر بحالة خضراء ويعرض أدواته.

### VS Code

1. اختر **التثبيت في VS Code** في لوحة الإعداد وأكّد التثبيت، أو احفظ الإعداد
   التالي في `.vscode/mcp.json`.
2. عندما يشغّل VS Code الخادم أول مرة، يطلب المفتاح في حقل كلمة مرور ويحفظه في
   مخزن الأسرار لديه. يبدو الإعداد هكذا:

```json
{
  "inputs": [
    {
      "id": "nibleaf-key",
      "type": "promptString",
      "description": "Nibleaf API key",
      "password": true
    }
  ],
  "servers": {
    "nibleaf": {
      "type": "http",
      "url": "https://api.docs.example.com/api/mcp",
      "headers": {
        "Authorization": "Bearer ${input:nibleaf-key}"
      }
    }
  }
}
```

3. افتح عرض المحادثة في وضع الوكيل (agent mode) وتحقق من ظهور أدوات Nibleaf.

### ChatGPT

يتصل ChatGPT بتسجيل الدخول لا بمفتاح؛ اتبع قسم «سجّل الدخول من ChatGPT» أعلاه. وتسجّل
شاشات الموصلات في claude.ai وClaude Desktop الدخول كذلك؛ راجع قسم «سجّل الدخول من
Claude» أعلاه.

### تحقق من الاتصال من داخل المساعد

اطلب من المساعد «استدعِ `get_capabilities`». يذكر الرد المشروع المرتبط بالمفتاح
ويعرض الأدوات والموجّهات التي يستطيع مفتاحك استخدامها بالضبط. إذا غابت أداة
تتوقعها، فإن إعدادك المسبق أو دورك الحالي لا يشملها.

## مثال: سدّ فجوة في المحتوى من البداية إلى النهاية

يستخدم هذا المثال مفتاحًا بإعداد **مساعد كتابة الدعم**.

1. **اعرف ما يفتقده القرّاء.** اطلب: «باستخدام `get_failed_searches` لآخر 7
   أيام، ما عمليات البحث التي لم تجد نتائج؟ اجمع العبارات المتشابهة معًا». ويمكنك
   أيضًا البدء من الموجّه `find_content_gaps`. وإذا أفادت الأداة بأن العبارات غير
   متاحة، فراجع قسم «ما الذي تخبرك به التحليلات وما لا تخبرك به» أدناه.
2. **ابحث قبل أن تكتب.** اطلب من المساعد تشغيل `search_pages` لكل مجموعة، حتى
   يوسّع صفحة موجودة بدل إنشاء صفحة مكررة.
3. **صِغ الإصلاح.** اطلب منه تحديث أقرب صفحة عبر `update_page`، أو إنشاء صفحة
   جديدة عبر `create_page_draft`. يُحفظ التغيير مسودةً في نسخة العمل، ويظل
   القرّاء يرون الموقع المنشور.
4. **راجع المسودة.** افتح الصفحة في محرّر Nibleaf واقرأها كما يقرؤها القارئ،
   وعدّلها بنفسك إن لزم. وإذا عدّلتها بعد أن قرأها المساعد، تفشل كتابته التالية
   بالرمز `mcp:revision_conflict` بدل أن تستبدل عملك، فيعيد قراءة الصفحة ويدمج
   تغييره فيها.
5. **عاين النشر.** اطلب `preview_publish`. تعرض المعاينة كل تغيير غير منشور في
   المشروع، بما فيه مسودات الآخرين، لأن النشر يشمل المشروع كله. وإذا احتوت
   القائمة على ما ليس جاهزًا، فتوقف ونسّق مع صاحبه.
6. **انشر بعد تأكيدك.** عندما تطمئن، اطلب من المساعد النشر. فيستدعي
   `publish_changes` مع `confirm: true` والرمز الناتج عن المعاينة. وإذا تغيّر أي
   شيء بعد المعاينة، يُرفض النشر بالرمز `mcp:preview_stale` وتعيد المعاينة.
7. **تحقق من الموقع المنشور.** اطلب منه متابعة `get_deployment` حتى تصبح عملية
   النشر جاهزة، ثم افتح الصفحة من دون تسجيل الدخول وابحث عن إحدى العبارات التي
   فشل البحث عنها. اتبع [النشر والتحقق](/ar/product/publishing) لإجراء فحص القارئ
   كاملًا.

تسجّل رسالة عملية النشر اسم المفتاح الذي نشر، ويسجّل سجل التدقيق المفتاح والشخص
الذي عمل باسمه، من دون تخزين محتوى الصفحة.

## كيف يكتب المساعد الصفحات

- **صيغة المحتوى.** محتوى الصفحة بصيغة Markdown أو MDX بحد أقصى 128 KiB للصفحة.
  ويمكن لكتلة YAML للبيانات الوصفية في مقدمة الملف أن تحدد `title` و`description`
  و`icon`، وتتقدّم وسائط الأداة الصريحة عليها. وهذا هو المحلّل نفسه الذي تستخدمه
  مزامنة Git، لذلك لا تُفك الأحرف المهرّبة في قيم البيانات الوصفية، تمامًا كما في
  مزامنة Git.
- **لا تُنفَّذ MDX أبدًا.** تُعرض صفحات القرّاء عبر `react-markdown` مع
  `rehype-sanitize`، فتظهر تعبيرات MDX وأسطر `import` و`export` نصًا عاديًا ولا
  تُشغَّل.
- **الترجمات.** ينشئ `translate_page` الترجمة مسودةً باللغة المستهدفة. ويذكر مراجعة
  الصفحة المصدر التي ترجمها، فإذا تغيّر المصدر في الأثناء يُرفض الطلب بالرمز
  `mcp:revision_conflict` بدل حفظ ترجمة قديمة. وإذا كانت
  الترجمة موجودة، يفشل بالرمز `mcp:translation_exists` ويحدد `data.pageId` الصفحة
  الموجودة؛ فعدّلها عبر `update_page`. ولربط الصفحات، قد يضبط أيضًا مفتاح ترجمة
  مشتركًا على الصفحة المصدر وعلى صفحات اللغات الأخرى المرتبطة بها مسبقًا عبر
  المسار، باستخدام عملية الكتابة نفسها الآمنة من تعارض المراجعات.
- **إخفاء صفحة.** بعد النشر التالي، تخرج الصفحة المخفية عبر `set_page_visibility`
  من التنقّل وبحث الموقع وخريطة الموقع و`llms.txt`، ويتوقف رابطها عن عرضها. أما
  صفحاتها الفرعية فتخرج من التنقّل لكنها تبقى متاحة عبر روابطها الخاصة. ويُفشل أي
  رابط من صفحة ظاهرة إلى صفحة مخفية فحصَ الروابط المعطّلة عند النشر، فأصلح هذه
  الروابط أولًا.

## ما الذي يحمي توثيقك

- **المسودة أولًا.** لا تغيّر عمليات الكتابة إلا نسخة العمل، ولا يصبح شيء منشورًا
  قبل نجاح النشر.
- **معاينة ثم تأكيد.** يحتاج النشر إلى معاينة حديثة وتأكيد صريح يحمل رمز
  المعاينة. ومراجعة المعاينة قبل التأكيد خطوة موصى بها، لكن Nibleaf لا يستطيع
  فرضها. يرتبط الرمز بك وبالمشروع وبما سيُنشر بالضبط، وتنتهي
  صلاحيته بعد 10 دقائق، وهو صالح فعليًا لاستخدام واحد: فأي تعديل أو نشر أو تراجع
  إلى إصدار سابق بعد المعاينة، بما في ذلك النشر الذي وافقت عليه، يجعله قديمًا.
- **راجع قبل أن تؤكد.** يستطيع Nibleaf التحقق من أن التأكيد يطابق معاينة حديثة،
  لكنه لا يستطيع التحقق من أن شخصًا قرأها. فالمساعد الذي يعمل دون أن يسألك قد يؤكد
  النشر من تلقاء نفسه، لذلك احتفظ بصلاحية **مساعد كتابة الدعم** للمساعدين الذين
  تعمل معهم، وبصلاحية **القراءة فقط** لأي شيء يعمل دون إشراف.
- **قائمة التغييرات كاملة.** تذكر المعاينة ما يصل إلى 50 صفحة متغيرة، وأي إعدادات
  للموقع ستتغير، مثل السمة أو التنقل. وعندما تكون الصفحات المعلّقة أكثر من ذلك يخبرك
  المساعد، فراجع القائمة الكاملة في نافذة النشر في لوحة التحكم قبل الموافقة.
- **نشر على مستوى المشروع.** يتضمن النشر التغييرات غير المنشورة لكل الأعضاء في
  المشروع، لا تغييرات المساعد وحده.
- **لا استبدال صامت.** يذكر كل تعديل المراجعة التي بُني عليها.
- **لا تكرار عند إعادة المحاولة.** يستطيع المساعد إرفاق `clientRequestId` فلا
  يُطبَّق الطلب المعاد مرتين. ويُرفض استخدام المعرّف نفسه مع وسائط مختلفة.
- **لا حذف.** لا توجد أداة حذف، وإخفاء الصفحة قابل للتراجع.
- **المحتوى غير الموثوق يبقى بيانات.** قد يحتوي نص الصفحات وعبارات البحث
  وملاحظات القرّاء على أي شيء كتبه زائر أو مؤلف. يوجّه Nibleaf المساعد إلى عدم
  اتباع أي تعليمات ترد داخلها أبدًا. فإذا اقترح المساعد إجراءً لأن صفحة أو عبارة
  بحث «تطلب ذلك»، فارفضه.
- **الحدود.** لكل مفتاح حد للطلبات، وحد مستقل في الدقيقة لاستدعاءات أدوات الكتابة،
  وحد في الساعة لعمليات النشر. ولا يُحتسب `preview_publish` ضمن حد الكتابة.
- **سجل التدقيق.** تُسجَّل كل محاولة كتابة، سواء نجحت أو فشلت في التحقق من
  المدخلات أو رُفضت لعدم الصلاحية أو اصطدمت بتعارض أو بلغت حد المعدل أو أُعيد
  تشغيلها من إعادة محاولة. ولا تُخزَّن أبدًا مدخلات الأداة أو محتوى الصفحات.

## ما الذي تخبرك به التحليلات وما لا تخبرك به

تستخدم أدوات البحث الأرقام وقواعد الخصوصية نفسها التي يستخدمها قسم **البحث** في
لوحة التحليلات:

- يُحتسب البحث مرة واحدة، بوصفه العبارة النهائية التي كتبها القارئ، لا مرة مع كل
  ضغطة مفتاح.
- لا يظهر نص العبارة إلا إذا بحث عنها زائران على الأقل. أما العبارات الأندر
  فتُحتسب، لكنها تبقى مخفية.
- عمليات البحث الفاشلة هي عبارات لم تجد شيئًا، أو وجدت نتائج لم ينقر عليها أحد.

لا توجد عبارات البحث الفردية إلا إذا تحققت كل الشروط التالية:

- أن تعمل النسخة بتحليلات ClickHouse (`ANALYTICS_MODE=clickhouse`)؛
- أن يكون الموقع عامًا، وأن يفعّل مشرف عبارات البحث له: من **التحليلات ← البحث**
  اختر **تفعيل عبارات البحث**؛
- أن يسمح القارئ بالتحليلات، أو ألا يطلب الموقع الموافقة أصلًا.

وعند غياب العبارات تظل الأدوات تعيد المجاميع والنسب، مع تلميح يوضح السبب. ولا
تخزّن التحليلات العلائقية نص البحث ولا عدد النتائج ولا النقرات، لذلك لا تتاح فيها
عمليات البحث الفاشلة.

ويعرض `get_referrers` أيضًا نشاط زواحف الذكاء الاصطناعي عندما تعمل النسخة بتحليلات
ClickHouse: طلبات الزواحف، والصفحات التي جلبها مساعدو الذكاء الاصطناعي لشخص ما،
والزواحف نفسها، والصفحات الأكثر زحفًا.

تستطيع كل الإعدادات المسبقة، ومنها **القراءة فقط**، قراءة محادثات
[«اسأل المساعد»](/ar/product/ai-assistant) المحفوظة باستخدام `list_ai_conversations`
و`get_ai_conversation`: الأسئلة التي طرحها القرّاء، والإجابات، وتقييماتهم
وتعليقاتهم. وهي المحادثات نفسها التي يراها فريقك في **مساعد الذكاء الاصطناعي**،
وتسري عليها قواعد الخصوصية نفسها: لا يحفظ Nibleaf النص إلا أثناء تفعيل **حفظ
الأسئلة لتحسين التوثيق**، ويحاول حذف بيانات مثل عناوين البريد الإلكتروني وأرقام
الهواتف والمفاتيح قبل الحفظ، ولا يحفظ هوية القارئ أبدًا. يؤدي إيقاف الحفظ إلى التوقف
عن حفظ نص المحادثات الجديدة فقط، أما المحادثات المحفوظة سابقًا فتحتفظ بنصها وتستطيع
الأدوات قراءته حتى يحذف أحدٌ المحادثة أو تنتهي مدة الاحتفاظ. وللمحادثات التي حُفظت
أثناء إيقاف الحفظ، تعيد الأدوات الأعداد والتقييمات والتكاليف دون نص.

قيود أخرى:

- لا تحتوي أداة **هل كانت هذه الصفحة مفيدة؟** على حقل تعليق، لذلك تقتصر تقييمات
  الصفحات على التصويت بأنها مفيدة أو غير مفيدة.
- بيانات البحث والزواحف وتقييمات الصفحات غير مقسّمة حسب اللغة، لذلك تتجاهل هذه
  الأدوات عامل تصفية اللغة، وتذكر ذلك في ردها.

## استكشاف الأخطاء وإصلاحها

| ما يظهر لك | السبب | ما العمل |
| --- | --- | --- |
| `mcp:disabled` | MCP معطّل في النسخة. | اطلب من المشغّل تفعيله. |
| `auth:invalid_api_key` (HTTP 401) | انتهت صلاحية المفتاح، أو أُلغي، أو لُصق ناقصًا، أو أُزيل مالكه أو عُلّق حسابه أو حُذف. | أنشئ مفتاحًا جديدًا وحدّث العميل. |
| `auth:invalid_token` (HTTP 401) | فُصل الاتصال المرتبط بتسجيل الدخول، أو أُزيل الشخص الذي أنشأه أو أُوقف. | اربط المساعد من جديد وسجّل الدخول. |
| «انتهت صلاحية طلب الربط هذا» في المتصفح | مرّ أكثر من 10 دقائق بين بدء الربط والموافقة. | ابدأ الربط من جديد من المساعد. |
| `auth:insufficient_scope` أو `mcp:scope_required`، أو غياب أداة | الإعداد المسبق للمفتاح لا يشملها، أو دورك الحالي لا يسمح بها. | أنشئ مفتاحًا بإعداد مسبق أوسع، أو اسأل مشرفًا عن دورك. |
| `auth:insufficient_role` | لم يعد دورك الحالي يسمح بهذا التغيير. | اسأل مشرفًا عن دورك. |
| `mcp:actor_required` | ليس للمفتاح مالك فعّال، لذلك لا يستطيع الكتابة. | أنشئ مفتاحًا جديدًا خاصًا بك. |
| `mcp:revision_conflict` | غيّر أحدهم الصفحة بعد أن قرأها المساعد. وتتضمن بيانات الخطأ `currentRevision`. | اطلب من المساعد إعادة قراءة الصفحة عبر `get_page`، ودمج تغييره، ثم إعادة المحاولة بالمراجعة الجديدة. |
| `mcp:translation_exists` | للصفحة ترجمة موجودة بتلك اللغة، ويحددها `data.pageId`. | عدّل تلك الصفحة عبر `update_page`. |
| `mcp:preview_stale` | تغيّر شيء بعد `preview_publish`. | شغّل `preview_publish` من جديد، وراجع القائمة الجديدة، ثم أكّد. |
| `mcp:preview_expired` | مضى على رمز المعاينة أكثر من 10 دقائق. | شغّل `preview_publish` من جديد. |
| `mcp:preview_invalid` | الرمز غير صالح لهذا الشخص والمشروع. | شغّل `preview_publish` من جديد واستخدم الرمز الجديد. |
| `mcp:confirmation_required` | استُدعي `publish_changes` من دون `confirm: true`. | أكّد فقط بعد أن توافق على المعاينة. |
| `mcp:nothing_to_publish` | لا توجد تغييرات غير منشورة. | لا شيء يلزم فعله. |
| `mcp:publish_blocked` | النشر محظور، مثلًا بسبب مشكلات في إعادة التوجيه، كما يحدث تمامًا في لوحة التحكم. | أصلح المشكلة في لوحة التحكم، ثم أعد المعاينة. |
| `mcp:publish_in_progress` | ما زالت عملية نشر قيد البناء، لذلك تنتظر تعديلات الصفحات وعمليات النشر الجديدة. ولم يُحفظ شيء. | انتظر حتى يُظهر `get_deployment` أن عملية النشر جاهزة أو فاشلة، ثم أعد المحاولة. |
| `mcp:idempotency_conflict` | أُعيد استخدام `clientRequestId` نفسه مع وسائط مختلفة. | استخدم `clientRequestId` جديدًا لعملية الكتابة المختلفة. |
| `mcp:idempotency_in_progress` | ما زال طلب بالمعرّف `clientRequestId` نفسه قيد التنفيذ. | أعد المحاولة بعد قليل. |
| `http:rate_limited` | بلغتَ حد الطلبات أو الكتابة أو النشر. | انتظر المدة الواردة في `data.retryAfterSeconds` (أو `Retry-After`)، وأبطئ المساعد أو اجمع العمل في دفعات. |

عندما تطلب المساعدة، شارك معرّف الطلب الوارد في رسالة الخطأ، ولا تشارك أبدًا
المفتاح أو ترويسة `Authorization` أو محتوى الصفحات.
