دُمجت ستة طلبات سحب للإمكانات في مصدر Nibleaf على `main`. وهي تكوّن مستوى
تحكم مترابطًا للبحث والاستخدام والإضافات والسمات والتكاملات ووصول الوكلاء. هذه
إتاحة في المصدر وليست دليل نشر: لا يزال بيان الاستضافة الذاتية المثبت يشير إلى
v0.1.2، ولا تنفذ تغييرات التوثيق هذه نشرًا على Cloud أو الاستضافة الذاتية.

## البحث والإجابات الموثّقة

يدعم مجال البحث استرجاعًا مقيدًا بالمستأجر وعملية النشر واللغة والإصدار وتفويض
القارئ. تعرض إعدادات المشروع عدد النتائج ومرشحات اللغة والإصدار والإجابات
الموثقة الاختيارية. وتعرض التشخيصات الصحة والأعداد ورموز المشكلات الثابتة
ومعرّفات محدودة، ولا تعيد محتوى المستند أو المتجهات.

لا يمثل التشغيل الهجين ادعاءً عامًا بالجودة. أبقِ `SEARCH_RUNTIME=shadow` حتى
تدعم استعلامات قبول فعلية وأدلة المزوّد قرار التحويل. يظل التراجع الفوري
للاسترجاع هو `legacy`. تُحجب الإجابات التي لا تدعمها المصادر بدل اختلاقها. راجع
[تشغيل البحث والذكاء الاصطناعي](/ar/self-hosting/search-ai).

## حقيقة الاستخدام والاستحقاقات

تستخدم حقائق الاستخدام مقاييس محايدة عن المزوّد وكميات صحيحة دقيقة. يملك
Postgres الخطط والتعيينات والاستحقاقات ونقاط التحقق وإيصالات منخفضة الحجم
ومحدودة؛ ويخزن ClickHouse الاختياري الحقائق والتجميعات عالية الحجم. قد تكون
التغطية مكتملة أو جزئية أو غير متاحة. لا يُعرض السجل المفقود بوصفه صفرًا، ولا
تفعّل الإمكانية الفوترة أو المدفوعات.

تبقى الحدود إرشادية في مجموعة إمكانات المصدر هذه. ينتظر التصدير تسوية الاستخدام
المعلق أو المتأخر، ويغطي حذف الخصوصية المخزنين وحدود محو البحث. راجع
[قياس الاستخدام](/ar/self-hosting/usage-metering).

## الإضافات والموافقة

تجمع إضافات المشروع مساعدات تفاعل القرّاء والخصوصية والنشر خلف حالة دائمة
واستحقاقات صريحة. تسجل الملاحظات حدث انطباع محدودًا، وتتطلب روابط التعديل
والبلاغات قوالب URL آمنة، وتضبط الموافقة التحليلات الاختيارية، وتتحقق فحوص
النشر المحلية من الروابط الداخلية ومدقق لغوي يحمل بوضوح حالة المعاينة. راجع
[إضافات المشروع](/ar/product/add-ons).

## سمات التوثيق المحمولة

تملك Harbor وManuscript وSignal الآن بنى قارئ مختلفة بدل أن تكون إعدادات ألوان.
تستخدم السمات الثلاث عقد Markdown/MDX نفسه والرموز الدلالية والترجمة والبحث
والبيانات الوصفية وحد النشر غير القابل للتغيير. قوالب السمات ملفات JSON حتمية
متحقق منها بالمخطط ومن دون CSS أو JavaScript تنفيذي. تفصل صادرات Git المستقلة
بين ملفات المنصة والمحتوى المشترك والملفات التي يملكها العميل. راجع
[سمات التوثيق](/ar/product/themes).

## التكاملات وMCP

يفصل محرك التكاملات اتصالات المزوّدين الخارجيين عن الإضافات والاستخدام. يشفر
بيانات الاعتماد القابلة للتهيئة بمفتاح مخصص، وينقح الاستجابات وسجلات التدقيق،
ويستخدم المراجعات ومنع التكرار، ويتطلب تأكيدًا صريحًا للحذف الهدّام. لا يثبت
وجود مزوّد في الدليل إتاحة وقت تشغيله أو بيانات اعتماده.

يعرض MCP محولات قراءة مرتبطة بالمشروع للإمكانات والمحتوى المنشور وإعداد البحث
وتشخيصاته والاستخدام المجمع والاستحقاقات والإضافات ودليل السمات وقوالبها
وملخصات التكاملات وبيانات التشغيل المحدودة. ولا يمكنه النشر أو إعادة الفهرسة أو
تصدير الاستخدام أو قبول بيانات اعتماد المزوّد أو تغيير المجالات الجديدة.
تتحقق معاينة استيراد السمة من دون كتابة. راجع
[التكاملات](/ar/reference/integrations-engine) و[MCP](/ar/self-hosting/mcp).

## حدود الترقية

يجب تشغيل ترحيلات Postgres بترتيب الطابع الزمني، مع التكاملات قبل MCP لأن
التكاملات تملك `ApiKey.expiresAt`. ولترحيلات ClickHouse الاختيارية والتسوية
بوابتهما الخاصة. اقرأ [دليل الترحيل والتراجع المجمع](/ar/self-hosting/combined-release-migration)
قبل اختيار مراجعة مصدر أو صورة مستقبلية.

لا تستبدل برنامج تثبيت v0.1.2 أو ملخص Compose الرقمي أو مرجع الحاوية بهذه
الالتزامات. يحتاج الناتج المنشور مستقبلًا إلى بناء وفحوص أمان وترحيل وملخص رقمي
دقيق وملاحظات إصدار وتحقق من وقت التشغيل بعد تسجيل الخروج.
