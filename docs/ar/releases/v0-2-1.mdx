الإصدار v0.2.1 هو إصدار الاستضافة الذاتية المثبّت في البيان المحفوظ بالمستودع. يشير
إليه برنامج التثبيت الموجّه وملف Compose الخاص ببيئة الإنتاج والصورة المثبتة
`ghcr.io/lord007tn/nibleaf:v0.2.1`. وهو أول إصدار منشور بعد v0.1.2. بُنيت صورة
v0.2.0 لكنها لم تُنشر إصدارًا قط، لذا يتضمن v0.2.1 كل ما في
[ملاحظات v0.2.0](/ar/releases/v0-2-0) ويحل محلها. تجد القائمة الكاملة للتغييرات مع
أرقام طلبات السحب في ملف `CHANGELOG.md` في المستودع وفي صفحة الإصدار على GitHub.

يتضمن v0.2.1 أيضًا تحسينات أمنية، لذا ينبغي ترقية جميع التثبيتات المستضافة ذاتيًا.

للصور اللاحقة التي لا تتضمن pnpm، اتبع [صيغة أوامر التشغيل الجديدة](/ar/self-hosting/search-ai)؛ تبقى الأوامر أدناه خاصة بـ v0.2.1.

## ما الذي يتضمنه v0.2.1

كل ما جاء في v0.2.0:

- **البحث الهجين والإجابات الموثّقة.** مسار اختياري عبر Qdrant يجمع BM25 والمتجهات
  الكثيفة مع تصفية حسب المستأجر، للمحتوى العربي والإنجليزي والمختلط، مع تشخيصات
  فهرس آمنة للخصوصية وإجابات موثّقة اختيارية بالذكاء الاصطناعي. يبقى بحث Orama
  المدمج هو الافتراضي. راجع [تشغيل البحث والذكاء الاصطناعي](/ar/self-hosting/search-ai).
- **إضافات المشروع** مع إتاحة تراعي الاستحقاق وضوابط الموافقة وإجراءات للقرّاء
  وفحوص قبل النشر. راجع [إضافات المشروع](/ar/product/add-ons).
- **سمات التوثيق.** Harbor وManuscript وSignal، مع تبادل آمن للقوالب وتصدير
  مستودعات Git قابلة للتشغيل. راجع [سمات التوثيق](/ar/product/themes).
- **قياس الاستخدام** بكميات دقيقة واستحقاقات إرشادية. راجع
  [قياس الاستخدام](/ar/self-hosting/usage-metering).
- **تكاملات المشروع** مع بيانات اعتماد مشفّرة وتأكيدات وسجل تدقيق وتدوير للمفاتيح.
  راجع [التكاملات](/ar/reference/integrations-engine).
- **نقطة MCP مرتبطة بالمشروع**، مصادَق عليها بمفاتيح محدودة النطاق تنتهي صلاحيتها.
- **الاستيراد من GitBook.** استورد مستودع GitBook Git Sync عامًا بأقسامه وروابطه وكتله
  وصوره. راجع [ترحيل التوثيق](/ar/product/migration).
- **مواقع منشورة أسرع.** ينتقل القرّاء بين الصفحات دون إعادة تحميل كاملة.

الجديد منذ v0.2.0:

- **محادثة Ask AI.** يطرح القرّاء أسئلتهم على وثائقك المنشورة ويحصلون على إجابات
  قصيرة ترتبط بالأقسام التي جاءت منها. راجع [Ask AI](/ar/product/ai-assistant).
- **مزوّد الذكاء الاصطناعي الخاص بك.** اربط OpenAI أو OpenRouter بمفتاحك الخاص من أجل
  Ask AI ومساعد الكتابة في المحرر. راجع [ربط مزوّد الذكاء الاصطناعي الخاص بك](/ar/product/smart-ai).
- **مساعدات ذكاء اصطناعي تستطيع الكتابة.** عبر MCP، يستطيع المساعد إنشاء المسودات
  وتحريرها وترجمتها ونشرها بعد معاينة مؤكدة، بتسجيل الدخول أو بمفتاح شخصي. راجع
  [العمل على وثائقك مع مساعد ذكاء اصطناعي](/ar/product/ai-assistants).
- **تقارير لمالكي الوثائق.** عمليات البحث التي لم تجد نتائج، وملاحظات القرّاء، وزيارات
  زواحف الذكاء الاصطناعي، والصفحات البطيئة. راجع [تحليلات التوثيق](/ar/product/analytics).
- **إعدادات افتراضية جديدة للذكاء الاصطناعي.** تستخدم الإجابات والمسودات GPT-6 Luna
  افتراضيًا. يبقى النموذج الذي ثبّته كما هو، ولا تحتاج إلى إعادة الفهرسة.
- **تضمينات بحث أكبر.** يستخدم البحث الهجين افتراضيًا
  `openai/text-embedding-3-large` بـ 3072 بُعدًا، فيجد إجابات الأسئلة العربية
  والمختلطة أكثر. يحتاج فهرس البحث الهجين القائم إلى إعادة بناء لمرة واحدة؛ راجع
  [التثبيت أو الترقية](#التثبيت-أو-الترقية).
- **الدعوات والترقية إلى main.** ينتهي قبول الدعوة دائمًا في الموقع المدعو إليه، أيًا
  كانت طريقة تسجيل الدخول. ويعرض إجراء **Promote** ما سيغيّره في صفحات main قبل تنفيذه.

## ما الذي يحتاج إلى إعداد

تأتي عدة إمكانات داخل الصورة لكنها تبقى معطّلة حتى تضبطها:

| الإمكانية | الوضع الافتراضي | ما تحتاج إليه |
| --- | --- | --- |
| البحث الهجين | معطّل، ويخدم البحث المدمج القرّاء | خدمة Qdrant عبر ملف البحث الإضافي، ومزوّد ذكاء اصطناعي للتضمينات، وانتقال مُقيَّم في `SEARCH_RUNTIME` |
| الإجابات الموثّقة وAsk AI | معطّلة | خدمة Qdrant عبر ملف البحث الإضافي، ومزوّد ذكاء اصطناعي (يحتاج مزوّد المثيل أيضًا إلى `SEARCH_ANSWER_ENABLED=true`)، وفهرس منشور بحالة READY، وتفعيلها لكل موقع |
| مساعد الكتابة بالذكاء الاصطناعي | مخفي دون مزوّد | `OPENROUTER_API_KEY`، أو اتصال الموقع بمزوّده الخاص |
| اتصالات المواقع بمزوّدي الذكاء الاصطناعي | غير متصلة | `INTEGRATION_CREDENTIAL_ENCRYPTION_KEY` على API وعامل المعالجة |
| نقطة MCP | معطّلة (`MCP_ENABLED=false`) | أن يفعّلها المشغّل. ويحتاج تسجيل دخول عملاء MCP أيضًا إلى `BETTER_AUTH_URL` يبدأ بـ HTTPS |
| تحليلات ClickHouse والتقارير | معطّلة | خدمة ClickHouse تشغّلها بنفسك، مع بيانات الاعتماد والترحيلات ومسار `ANALYTICS_MODE` في [دليل ClickHouse](/ar/self-hosting/clickhouse-analytics). لا يمرّر `docker-compose.prod.yml` هذه الإعدادات، لذا أضفها بنفسك. |

لا يفعّل قياس الاستخدام الفوترة أو المدفوعات، وتبقى استحقاقاته إرشادية.

## حدود المنصة والواجهة

- تدعم الصورة المنشورة البنية `linux/amd64` فقط، ويتوقف برنامج التثبيت على البنى
  الأخرى.
- لا يتضمن `docker-compose.prod.yml` خدمة Qdrant ولا ClickHouse.
- تقدم الواجهة 12 خيارًا للغة، وما زالت بعض النصوص بالإنجليزية.

راجع [القيود المعروفة](/ar/reference/known-limitations) لحدود المنتج الأوسع.

## التثبيت أو الترقية

- **تثبيت جديد:** اتبع [التثبيت المستضاف ذاتيًا](/ar/getting-started/self-hosted).
  يتحقق أمره من بصمة SHA-256 لبرنامج تثبيت v0.2.1 قبل تشغيله.
- **من v0.1.2:** لا يكفي تغيير وسم الصورة. اتبع
  [دليل الترقية](/ar/self-hosting/upgrade-v0-2)، فهو يرحّل جداول المهام المتكررة
  على مرحلتين ويغطي النسخ الاحتياطي وملف Compose وإعدادات البيئة الجديدة. تُنفَّذ
  تسعة عشر ترحيلًا لقاعدة البيانات، وهي أحادية الاتجاه.
- **من صورة v0.2.0:** لا تحتاج إلى المرحلة الوسيطة. أنشئ نسخة احتياطية، واستبدل ملف
  Compose، وثبّت v0.2.1، كما في [النسخ والترقية](/ar/self-hosting/backups-upgrades).
- **إذا كنت تضبط `WORKER_QUEUES`:** أضف `erasure`؛ وإلا بقيت ملفات المشاريع المحذوفة
  بعد الترقية في التخزين.
- **إذا كنت تشغّل البحث الهجين بالفعل:** لا يتضمن v0.1.2 بحثًا هجينًا، لذا لا ينطبق هذا
  إلا على فهرس بنته صورة v0.2.0 أو بناء من المصدر. بعد الترقية يحصل القرّاء على نتائج
  الكلمات المفتاحية، وتتوقف الإجابات بالذكاء الاصطناعي وAsk AI مؤقتًا، حتى تعيد بناء
  الفهرس وتنتقل إلى المجموعة الجديدة. اطلب إعادة البناء:

  ```bash
  docker compose exec -T server pnpm --filter @nibleaf/server search:reindex-all
  ```

  انتظر حتى يصبح فهرس كل موقع بحالة READY بالإعدادات الجديدة، ثم بدّل الاسم المستعار:

  ```bash
  docker compose exec -T -e QDRANT_PREVIOUS_COLLECTION=nibleaf_search_active_v1_1536 -e QDRANT_SWITCH_TO=nibleaf_search_active_v2_3072 server pnpm --filter @nibleaf/qdrant alias:switch
  ```

  احتفظ بالمجموعة `nibleaf_search_active_v1_1536` حتى تطمئن إلى النتيجة. للبقاء على
  النموذج السابق أو للتراجع، اتبع [تشغيل البحث والذكاء الاصطناعي](/ar/self-hosting/search-ai).
- **إذا فشل شيء:** راجع [استكشاف الأخطاء وإصلاحها](/ar/self-hosting/troubleshooting).
