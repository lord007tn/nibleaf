This page compares Nibleaf with the components and authoring features in the
[Mintlify documentation](https://www.mintlify.com/docs/components/index), as
published on 7 November 2026. It is a working tracker: each row names the change
that closes a gap, and rows move to **Has** as those changes ship.

## How to read the statuses

- **Has**: you can insert and edit it in the visual editor, it survives switching
  to source mode, Git sync, and exports, and it renders in the Harbor, Manuscript,
  and Signal themes in light and dark mode, left to right and right to left.
- **Partial**: it works, but the listed Mintlify options or editing paths are missing.
- **Missing**: Nibleaf doesn't support it yet.
- **Out of scope**: not planned, for the reason given.

The **Planned in** column refers to the parity work stream: 3 component options,
4 code blocks, 5 new components and media, 6 editing experience, and 7 reusable
content and page metadata.

Unknown components never break a page. The editor keeps any tag it can't edit as
a protected block, so saving never drops it.
