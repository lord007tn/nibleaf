Plume pages are written in **Markdown** with optional **MDX** components. This page
covers the authoring features available in the editor.

## Frontmatter

Every page starts with a YAML frontmatter block that controls its metadata and
position in the navigation:

```mdx
---
title: Writing pages
description: Author content in Markdown and MDX.
icon: FileText
---
```

## Markdown basics

Standard Markdown works as you'd expect — headings, **bold**, _italic_, lists,
tables, blockquotes, and links. GitHub-flavored Markdown extensions (task lists,
tables, strikethrough, autolinks) are enabled.

```md
## A heading

- A list item
- Another item with a [link](/docs)

> A blockquote for emphasis.
```

## Callouts

Use callouts to draw attention to important information.

<Callout type="info">
  Informational notes use the `info` type.
</Callout>

<Callout type="warn">
  Use `warn` for things readers should be careful about.
</Callout>

<Callout type="error">
  Use `error` for breaking changes or destructive actions.
</Callout>

```mdx
<Callout type="warn">
  Use `warn` for things readers should be careful about.
</Callout>
```

## Code blocks

Fenced code blocks are syntax-highlighted automatically. Add a language hint for
the best result:

````md
```ts
export function greet(name: string) {
  return `Hello, ${name}`;
}
```
````

Renders as:

```ts
export function greet(name: string) {
  return `Hello, ${name}`;
}
```
