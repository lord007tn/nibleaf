Midad turns a folder of Markdown into a fast, searchable documentation site. This
page explains the moving parts so the rest of the docs make sense.

## Core concepts

<Cards>
  <Card title="Project">
    A documentation site. It owns its pages, navigation, theme, and domain.
  </Card>
  <Card title="Page">
    A single Markdown/MDX document with frontmatter (title, description, slug).
  </Card>
  <Card title="Version">
    An immutable snapshot of a project's content, created when you publish.
  </Card>
  <Card title="Deployment">
    A built, served version mapped to a domain — the thing your readers see.
  </Card>
</Cards>

## How a request flows

When you work in Midad, the services cooperate like this:

<Steps>
  <Step>
    You edit a page in the **dashboard** (`@midad/app`, port 4310). The Markdown
    editor saves drafts to the API as you type.
  </Step>
  <Step>
    The **API** (`@midad/server`, port 4311) persists content to PostgreSQL via
    Prisma and stores uploaded assets in MinIO/S3.
  </Step>
  <Step>
    When you hit **Publish**, the API enqueues a build job on BullMQ.
  </Step>
  <Step>
    The **worker** (`@midad/worker`, port 4312) renders the version, builds the
    Orama search index, and writes the output to object storage.
  </Step>
  <Step>
    Readers hit the published site on its custom domain, served fast with
    search ready to go.
  </Step>
</Steps>

## The stack

| Layer | Technology |
| --- | --- |
| UI framework | TanStack Start (React 19) |
| API framework | Hono |
| ORM / database | Prisma + PostgreSQL |
| Job queue | BullMQ + Redis |
| Object storage | MinIO (S3-compatible) |
| Search | Orama |

<Callout type="info">
  Every service is its own workspace package under `apps/*` in a pnpm monorepo.
  Shared code (auth, database client, validators, logger) lives under
  `packages/*` and is published internally as `@midad/*`.
</Callout>

## What you can do with Midad

- Author docs in Markdown/MDX with a live-preview editor
- Organize pages into navigable groups
- Publish **versioned** releases and roll back instantly
- Serve full-text **search** powered by Orama
- Map projects to **custom domains**
- Track basic **analytics** on your published docs
- **Self-host** the whole thing with Docker
