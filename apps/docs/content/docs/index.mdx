Plume is an open-source documentation platform you can run on your own
infrastructure. Write your docs in Markdown, preview them instantly, publish
versioned releases, and serve a fast, fully-searchable site to your readers — no
SaaS lock-in, no per-seat pricing.

## What's in the box

Plume is a pnpm monorepo split into focused services:

| Service | Package | Port | Role |
| --- | --- | --- | --- |
| Dashboard | `@plume/app` | 4310 | Authoring UI: editor, projects, publishing |
| API | `@plume/server` | 4311 | Hono API, auth, persistence |
| Worker | `@plume/worker` | 4312 | Background jobs: builds, search indexing |
| Marketing site | `@plume/www` | 4313 | Public landing pages |
| Docs | `@plume/docs` | 4314 | This documentation site |

## Architecture at a glance

- **Frontend** — [TanStack Start](https://tanstack.com/start) (React 19, SSR + file-based routing)
- **API** — [Hono](https://hono.dev) running on Node
- **Database** — PostgreSQL via [Prisma](https://www.prisma.io)
- **Background jobs** — [BullMQ](https://docs.bullmq.io) backed by Redis
- **Object storage** — [MinIO](https://min.io) (S3-compatible) for assets and built sites
- **Search** — [Orama](https://orama.com) full-text index
