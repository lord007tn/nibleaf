# Nibleaf guide academy fixtures

These files are deterministic teaching inputs, not production measurements.

- `markdown-round-trip.mdx` exercises headings, bidirectional text, code, tables, and supported MDX components.
- `migration-url-map.csv` records an example one-to-one redirect contract. Replace the example hosts before a rehearsal.
- `arabic-search-corpus.json` and `arabic-search-queries.json` provide a small labeled Arabic retrieval set. Expected document IDs are relevance judgments, not measured scores.
- `resource-sizing-observations.csv` shows the columns to capture during a representative observation window. Its values are illustrative and must not be treated as Nibleaf requirements.

No file contains customer data, credentials, analytics identifiers, or production URLs.
