OG cards use Noto Sans Arabic (variable TTF, default Regular weight), licensed
under SIL OFL 1.1; see OFL.txt. These fonts remain on the API server.

Source: https://github.com/google/fonts/tree/main/ofl/notosansarabic

This distribution includes Arabic, vocalization marks and Latin in one face,
so mixed-script runs do not depend on native font fallback. resvg performs
Unicode bidi ordering and shaping before rasterizing. The API build copies
the font and license into dist/assets/og.
